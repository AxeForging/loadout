# impeccable — loadout

## Design Context

### Users
Developers who live in terminals and coding agents (Claude Code, Codex, Gemini CLI, Cursor). They open the web UI next to a dark IDE/terminal — usually to get an overview of drift across agents, review what a sync would change, browse/share the store, or run the builder where a rich form beats a TTY questionnaire. Solo toolsmiths and team leads distributing a shared loadout. They are expert users: density and speed over hand-holding, but the tool's core promise (never write without asking) must be *felt* in the UI.

### Brand Personality
**Equipped · dependable · quick.** "loadout" is the gaming term for the gear kit you carry between matches; the org is AxeForging (forge, workshop, tools that feel hand-made and solid). The UI should feel like a well-organized equipment room / armory: labeled gear, status boards, everything in its slot — not a SaaS analytics dashboard. Trust comes from clarity about state (in-sync / drifted / conflict) and explicit, gated actions.

### Aesthetic Direction
Dark theme (derived: used beside dark terminals/IDEs, often at night). Utilitarian workshop with forge warmth: deep warm-steel surfaces, ember-orange accent used sparingly (pending work, primary actions), muted signal colors for sync states. Equipment-tag visual language: kebab-case IDs in mono on tag-like chips, square status markers (checklist, not traffic lights), overline section labels like stencil labels on crates. Anti-references: generic SaaS card grids, neon cyberpunk, glassmorphism, purple-blue gradients.

Type: **Chakra Petch** (display — squared, equipment-label, subtly gamey) · **Schibsted Grotesk** (body) · **Red Hat Mono** (paths, hashes, IDs). Self-hosted via @fontsource — the binary serves everything offline.

### Design Principles
1. **State is the hero** — drift states are the product; they get the strongest visual encoding (color + square marker + label, never color alone).
2. **Gated actions are visible rituals** — applying changes is a two-step, docked review panel (plan → apply), never a hidden confirm or a modal.
3. **Density with rhythm** — tables and lists over cards; hierarchy from spacing and type scale, not boxes in boxes.
4. **Ember is rare** — the accent appears only where action or attention is genuinely needed (10% rule).
5. **Everything labeled like gear** — mono IDs, kind glyphs, overline crate-labels; the armory metaphor carries the personality without decoration.
