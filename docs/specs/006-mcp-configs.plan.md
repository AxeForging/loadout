## Risks

- **State-key encoding** is the only persisted-format change. Mitigation: agent-home entries keep today's bare relPath keys (no migration, old files load); new prefixes only appear once an MCP artifact is synced. Rollback: remove MCP artifacts and sync — orphan cleanup handles the rest; a downgraded binary simply ignores prefixed keys it never matches (verify in the old-format state test).
- **`~/.claude.json` is loadout's first write outside an agent home.** The new path fence + the extended no-confirm-no-write invariant test are the guards; `MergeJSON` only upserts `mcpServers.<id>`, and the existing semantic-no-op behavior in `jsonMerge` avoids phantom drift on this large user-state file.
- **Codex TOML block** may not generalize cleanly from HTML-comment markers — explicitly droppable (SHOULD) without touching the rest.
- **MergeJSON removal is unsupported today** (`removal.go:185`) — uninstalling an MCP artifact leaves the JSON entry with a removal warning, same as hooks' settings fragments. Acceptable v1; note in README.
